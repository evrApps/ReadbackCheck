# Contributing

Thank you for your interest in Readback Check.

For now this repository does not accept code contributions from outside EVRApps: pull requests will be closed without being merged. This will change once a contributor agreement is in place.

Reports are welcome. Open an issue for:

- a bug, with the report of the test (Window ▸ Past Tests ▸ Show in Finder) and your macOS version;
- a result that looks wrong for an app or a disk;
- a disk, card reader or network share on which the test can't run.
